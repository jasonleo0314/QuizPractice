# QuizPractice

QuizPractice 是一个基于 .NET 8 的题库练习程序，面向“持续刷题、自动归档、循环巩固”的学习场景。

## 项目简介

程序会从题库文件中随机抽题，支持单选、多选、判断等题型。每次作答后都会自动保存进度，并生成 Excel 统计报告，方便你长期追踪自己的掌握情况。

## 环境要求

- .NET 8 SDK
- 推荐使用 Visual Studio 2026 或任意支持 .NET 8 的 IDE

## 使用方法

1. 准备题库文件 `QuizPractice.tsv`，并将其放在程序可读取的位置。
2. 启动程序后，系统会自动加载题库与历史进度。
3. 程序优先随机抽取未作答题目；未作答题目都练过后，再随机抽取未归档题目。
4. 输入答案后立即判题、展示解析状态，并自动保存进度。
5. 当所有题目都达到归档条件后，程序会提示已完成全部题目。
6. 任意时刻输入退出键（默认 `q` / `Q`）即可保存并退出，下次启动可继续之前的进度。

## 输入格式

题库文件使用 **TSV（制表符分隔）** 格式，首行可作为表头，后续每行对应一道题。

每行字段顺序如下：

1. 题型
2. 题号
3. 题干
4. A 选项
5. B 选项
6. C 选项
7. D 选项
8. 正确答案

示例：

```tsv
题型	题号	题干	A	B	C	D	正确答案
单选	1	以下哪个是 .NET 的运行时？	CLR	JVM	V8	Node	A
多选	2	以下哪些属于 C# 关键字？	class	var	json	async	ABD
判断	3	.NET 8 属于现代 .NET。	正确	错误			A
```

说明：

- 系统会自动去除空选项，因此判断题或少选项题也可以使用同一格式。
- 正确答案会自动规范化，系统会忽略大小写，并按字母顺序处理多选答案。
- 多选题可输入多个字母，例如 `ABD`。

## 各个面板含义

启动后，控制台会以多个面板展示练习信息：

- **顶部标题面板**：显示标题、说明文字和当前时间。
- **统计表格**：显示总题数、已归档题数、待练习题数、作答次数、正确次数、错误次数、归档率、正确率。
- **练习说明面板**：显示已加载题目数、归档条件、统计频率和快捷退出键。
- **题目面板**：显示当前题干与选项。
- **本题进度面板**：显示该题的作答次数、正确/错误次数、归档状态与归档条件。
- **作答反馈面板**：显示你本次答案、标准答案、是否答对、是否已归档，以及当前累计进度。
- **完成提示面板**：当所有题目归档后显示最终完成状态与整体正确率。

## 题目归档方式

本项目不是简单“做完一遍就结束”，而是按掌握度归档：

- 每道题都会记录：作答次数、答对次数、答错次数、连续答对次数、最后一次答案、最后作答时间。
- 默认归档条件是：**答对次数大于答错次数**。
- 当题目满足条件后，会被标记为“已归档”；后续抽题会先抽未作答题目，未作答题目都练过后再随机抽未归档题目。
- 这样可以把你的注意力集中在真正薄弱的题目上，而不是重复刷已经掌握的题。

## 输出文件

程序会自动输出并维护以下文件：

- **`quiz-progress.json`**：进度文件，保存每道题的作答历史、归档状态和累计统计。
- **`作答情况.xlsx`**：Excel 报表，包含三类工作表：
  - **统计概览**：整体完成度与正确率
  - **题目明细**：每道题的详细作答记录
  - **按正确错误次数划分**：按掌握程度分组的题目列表

## 最终能达到的训练效果

通过这种刷题方式，最终能形成以下训练效果：

- **从“未练”走向“掌握”**：系统会先覆盖未作答题目，再回到需要巩固的题目。
- **从“广撒网”走向“精准补弱”**：系统会持续把未掌握的题目放回练习池。
- **从“记答案”走向“建立长期记忆”**：重复出现的薄弱题会强化记忆，降低遗忘率。
- **从“主观感觉”走向“数据驱动”**：正确率、错误率、完成率都能量化查看。

## 通过刷题库学习的优势

和一次性看资料相比，题库式训练有这些优势：

- **反馈快**：答完立刻知道对错，不会把错误理解拖到后面。
- **针对性强**：系统自动聚焦你没掌握的题目，节省复习时间。
- **可重复、可追踪**：每次练习都有记录，能看到自己是否真的进步。
- **更适合记忆巩固**：高频回炉的题目更容易形成长期记忆。
- **有完成目标感**：归档机制让“掌握”变成明确标准，而不是模糊感觉。

## 快速开始

控制台程序：

```bash
dotnet restore
dotnet build
dotnet run --project QuizPractice.csproj
```

网页程序：

```bash
dotnet run --project QuizPractice.Web/QuizPractice.Web.csproj
```

启动后在浏览器访问终端输出的地址；如果需要在手机微信内置浏览器访问，请让手机与运行程序的电脑处于同一网络，并使用电脑局域网 IP 加端口访问。

## 项目结构（示例）

- `Program.cs`：程序入口
- `Models.cs`：题目、进度、统计模型
- `Services.cs`：题库读取、进度保存、Excel 导出
- `QuizConsoleRenderer.cs`：控制台界面渲染
- `QuizPractice.Web/`：网页程序，复用同一套题库、判题、进度保存和 Excel 导出服务
